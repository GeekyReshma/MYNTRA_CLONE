# 🛍️ Myntra Clone

A **Myntra-inspired e-commerce website UI** created using **HTML and CSS**.
This project recreates the visual structure of a modern fashion-shopping website with a navigation bar, search interface, promotional banner, product/category sections, and footer.

## ✨ Features

* 🏠 Myntra-inspired homepage layout
* 🧭 Navigation bar with:

  * Men
  * Women
  * Kids
  * Home & Living
  * Beauty
  * Studio
* 🔍 Search bar for products, brands and more
* 👤 Profile section
* ❤️ Wishlist section
* 🛍️ Shopping bag section
* 🖼️ Promotional banner
* 🏷️ "Medal Worthy Brands to Bag" section
* 👗 "Shop by Category" section
* 📱 Clean and organized e-commerce layout
* 🎨 Hover effects and consistent visual styling
* 📌 Footer with shopping-related links

## 🛠️ Technologies Used

* **HTML5** — Structure and content
* **CSS3** — Styling, layout and visual design
* **Google Material Symbols** — Interface icons
* **Images/Web Assets** — Product, category and promotional visuals

## 🎨 Design Highlights

The project focuses on recreating the visual experience of a fashion e-commerce platform through:

* Clean navigation hierarchy
* Consistent typography
* Product/category grid layouts
* Promotional visual sections
* Proper spacing and alignment
* E-commerce focused UI composition
* Simple hover interactions

```bash

```

2. Open the project folder.

3. Open `index.html` in your browser.
